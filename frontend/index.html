⚠️ Problem Statement

The Delhi-NCR Traffic & Environmental Crisis

Current Navigation Limitations:

  • Static Distance Bias: Traditional GPS uses shortest geometric distance, trapping commuters in gridlocked arterial roads.
  • Single-Objective Blindness: Existing apps ignore vehicle powertrain physics (EV vs Diesel SUV) and environmental emissions.
  • Weather Fragility: Monsoon underpass flooding and winter smog spikes cause catastrophic sudden chokepoints.

Our Breakthrough Innovation:

  • Predictive ML Weights: Dynamically adjusts graph edge travel times before vehicles enter bottlenecks.
  • Multi-Criteria Pareto Router: Simultaneously computes Fastest, Lowest $CO_2$/Fuel, and Weather-Safe routes.
  • Sub-Millisecond C++ Core: Ultra-fast execution ready for city-wide fleet deployments.

⚡ C++ Engine & Graph Theory

Microsecond Graph Optimization Core

Min-Heap Priority Queue

Implemented with std::priority_queue in C++17, reducing time complexity to $O((V + E) \log V)$ for rapid routing.

Dynamic Edge Ingestion

ML-predicted edge weights are passed via fast JSON stream, allowing continuous real-time graph re-weighting.

Path Reconstruction

Parent predecessor array tracks exact node sequence and road IDs, returning structured routing payloads instantly.

// C++ Min-Heap Dijkstra Excerpt
priority_queue<pair<double, int>, vector<pair<double, int>>, greater<pair<double, int>>> pq;
dist[source] = 0.0;
pq.push({0.0, source});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue;
    if (u == destination) break;
    for (const auto& edge : adj[u]) {
        if (dist[u] + edge.weight < dist[edge.to]) {
            dist[edge.to] = dist[u] + edge.weight;
            parent[edge.to] = {u, edge.road_id};
            pq.push({dist[edge.to], edge.to});
        }
    }
}
